# Repository instructions

- Use English for documentation, source comments, and application text.
- Keep comments to a minimum. Only add comments that explain non-obvious behavior or provide high-level context, such as a class's purpose.
- Do not generate unit tests. Integration tests are allowed.
- When creating commits, follow Conventional Commits: `type(scope): description`, with an optional scope (for example, `fix(audio): restore the previous input device`).
